# Nicholson Bookkeeping Solutions

One-page marketing website for Nicholson Bookkeeping Solutions — friendly,
professional bookkeeping from Jackie Nicholson for individuals, sole traders
and small businesses.

Built with React, TypeScript, Vite, Tailwind CSS and shadcn/ui.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs static site to dist/
```

Live preview: https://zius2g4343zeo.kimi.page
